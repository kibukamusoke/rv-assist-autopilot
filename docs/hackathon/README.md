# Hackathon compliance

This directory is the durable reference for keeping RV Assist Autopilot within the All Things Agentic Hackathon and Taskmaster track parameters.

## Documents

- [Requirements register](requirements-register.md): requirements, sources, confidence, current evidence, and gaps.
- [Compliance checklist](compliance-checklist.md): repeatable checks before development decisions, releases, and submission.

## Operating rule

Do not rely on memory for competition requirements. Before a decision that affects eligibility, track fit, required technology, judging evidence, or submission packaging:

1. Read the requirements register.
2. Check the official rules for changes.
3. Record the official URL, exact requirement in paraphrase, and verification date.
4. Update the compliance status and evidence.
5. Resolve any `BLOCKED` item before final submission.

Official competition rules outrank this repository, prior conversations, promotional articles, and engineering preferences.
